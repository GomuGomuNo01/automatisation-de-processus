Relais en 40 secondes

Six automatisations Python enchaînées en un pipeline : il surveille le stock, envoie les alertes, remplit le formulaire d'urgence, compile la production et relève les prix, puis recommence à son rythme. Le son est activé : la musique a été composée pour la vidéo.

Vidéo animée image par image en Python (Pillow), sur une musique originale synthétisée par le code (numpy) : aucun extrait, aucun échantillon, aucune banque d'images, donc aucun droit tiers.
